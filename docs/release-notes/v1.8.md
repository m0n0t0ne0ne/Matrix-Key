Pick several separate sections of text in Scan text.

### New
- **Multi-select** button under the scanned photo. When it's on, each drag adds that run of words to what's already highlighted instead of replacing it, so you can pick text from different parts of the photo. Tap a highlighted word to remove it. Turning it on while everything is highlighted clears the highlight first, so you start from nothing.
- Tap the button again (it shows **Multi ✓** while on) to go back to the normal behaviour, where a drag selects just that one run.

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings and dictionary. Requires Android 10+ on a 64-bit phone.
