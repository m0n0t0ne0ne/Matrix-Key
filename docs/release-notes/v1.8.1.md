A lone "i" now becomes "I" everywhere, and swiping uses the words around it better.

### Fixed
- **"i" on its own is now "I"** in apps like Google Keep, where letters you tap go straight into the note. It changes when you finish the word (space, punctuation or Enter). Words that only start with i, like "it", "is" and "it's", are left alone. Press ⌫ right after if you really meant a lowercase "i".
- **Swipes now use the word you just tapped as context.** In Keep and similar apps, a swipe used to see the last *swiped* word instead, so "I eat" could come out as "I easy". The keyboard now reads the previous word from the text itself.
- **Fixing a swiped word teaches the right thing.** Picking "make" in place of a wrong "maybe" now learns "I → make" and forgets the wrong guess, instead of learning "maybe → make". The next swipe also gets "make" as its previous word, not "maybe".
- **Word pairs you've learned now also work at the start of a sentence** ("It …", "The …"); before, only the lowercase versions were used.

### Changed
- More common word pairs for swiping, for example "I eat / make / feel / hope …", "it seems / looks / sounds …" and "upper case".
- After words like "be", "to" and "the", swipes no longer pick "you're", "I'm" and similar words, which can't come next ("to be upper", not "to be you're").
