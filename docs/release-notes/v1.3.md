Emoji search, and a tidier toolbar.

### New
- **Search emoji**: open emoji with the smiley key and tap **Search emoji** at the top. Type or swipe a word ("heart", "thumbs up", "pizza", "lol") and matching emoji appear in a row above the keys as you type; tap one to insert it and keep going. Press enter to see every match in the emoji panel. Search uses each emoji's official name plus everyday words.

### Changed
- **No duplicate emoji button**: the toolbar no longer has an emoji button, since the smiley key next to the space bar already opens emoji. If you turn that key off in *Settings › Preferences*, the toolbar button comes back.

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings and dictionary. Requires Android 10+ on a 64-bit phone.
