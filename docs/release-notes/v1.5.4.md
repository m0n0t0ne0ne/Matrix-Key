Scan text: a sure way to get the text into your message.

### Fixed
- After **Insert text**, the keyboard still tries to type the scanned text in by itself, but now checks that it actually arrived. Some apps (including Google Messages) ignore text sent while their message box is still getting ready, so if it didn't arrive, an **Insert scanned text** button appears in the suggestion bar. Tap it and the text goes in. The button stays until you use it (or for 10 minutes).

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings and dictionary. Requires Android 10+ on a 64-bit phone.
