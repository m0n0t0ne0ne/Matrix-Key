First public release of **Matrix Key**, a dot-matrix keyboard for Android built for Nothing phones.

### Features
- **Nothing look**: NDot key font (or the open-source Doto), dotted icons, floating or boxed keys, light, dark and dynamic themes, and Rboard / Gboard theme import
- **Smart typing**: suggestions that scroll, next-word prediction, autocorrect that knows key positions, contractions, and learning that stays on your phone
- **Glide typing** with a themed trail, and spacebar cursor control with a haptic tick on every step
- **Personal dictionary**: your own words, names and email show up when you type or swipe
- **Proofreading**: tap any word in your text to get its suggestions back
- **Number pad and quick math**: the 1234 key opens a number pad, and typing `5+5(6/2)=` fills in the answer
- **Toolbar**: emoji, clipboard history, GIF search (GIPHY or KLIPY), AI writing (Gemini free tier with Groq backup), voice typing and Scan text

### Install
Download the APK below, open it on your phone and allow *Install unknown apps*. Requires Android 10+ on a 64-bit phone.

If you installed a test build ("Update N"), uninstall it first: 1.0 is signed with a new key. Export your dictionary first in *Settings › Dictionary › Export* and import it afterwards.
