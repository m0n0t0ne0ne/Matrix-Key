The enter key makes a new line in messaging apps.

### Fixed
- **New line, not send**: in message boxes (Google Messages, chat apps, email) and any multi-line field, the enter key now always starts a new line. Use the app's own send button to send. Some apps were treating the keyboard's enter press as "send"; the line break is now typed as text, so it can't be mistaken for a send.
- Search boxes and single-line fields keep their usual action (search, go, next, done).

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings and dictionary. Requires Android 10+ on a 64-bit phone.
