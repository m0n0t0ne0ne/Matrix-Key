Privacy and security hardening.

### Changed
- **Nothing moves to a new phone**: learned words, clipboard history, settings and API keys were already left out of cloud backups; they're now also left out of Android's phone-to-phone transfer.
- **Microphone is optional**: setup no longer counts the microphone as a required step. It's only needed for voice typing.
- **Scan text** deletes the photo as soon as you leave the screen.
- **HTTPS only**: the keyboard refuses any non-HTTPS address.
- **Safer imports**: theme and font files are size-limited.

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings and dictionary. Requires Android 10+ on a 64-bit phone.
